小程序码工具 — 两种交互方案对比

整体布局：顶部选择小程序 → 下方表单生成。两种方案的区别在于「类型选择」和「表单」的组织方式。

A
方案 A：单页 Tab 切换

所有类型共用一个页面，通过顶部 Tab 切换不同类型，切换后表单字段随之变化。

┌──────────────────────────────────────────┐
│ 选择小程序: [小程序A ▼] │
├──────────────────────────────────────────┤
│ [有限码] [无限码] [二维码] [Scheme] [Link] │
├──────────────────────────────────────────┤
│ │
│ 页面路径: [________________] (必填) │
│ 二维码宽度: [430___] px │
│ 是否需要透明底色: [否 ▼] │
│ ... │
│ │
│ [生成小程序码] │
│ │
│ ┌──────────────┐ │
│ │ [二维码图] │ ← 结果展示 │
│ │ 下载 | 复制 │ │
│ └──────────────┘ │
└──────────────────────────────────────────┘
  • ✓ 空间紧凑，一页搞定所有类型
  • ✓ 切换类型不丢失小程序选择
  • △ 不同类型的参数字段差异大，表单区域需要动态渲染
B
方案 B：左右分栏 + 类型列表

左侧列表展示所有类型，点击后在右侧显示对应表单和结果，类型间互不干扰。

┌──────────────┬───────────────────────────┐
│ 选择小程序: │ │
│ [小程序A ▼] │ 小程序码（有限） │
│ │ │
│ 生成类型: │ 页面路径: [__________] │
│ ● 小程序码-有限│ 宽度: [430] px │
│ ○ 小程序码-无限│ 透明底色: [否 ▼] │
│ ○ 普通二维码 │ ... │
│ ○ URL Scheme │ │
│ ○ URL Link │ [生成小程序码] │
│ │ │
│ │ ┌──────────────┐ │
│ │ │ [二维码图] │ │
│ │ │ 下载 | 复制 │ │
│ │ └──────────────┘ │
└──────────────┴───────────────────────────┘
  • ✓ 各类型独立，表单不互相干扰
  • ✓ 适合后续扩展更多类型
  • △ 占用更多水平空间
  • △ 切换类型需要重新点选，不能一眼看到所有类型

我的推荐：方案 A

理由：小程序码工具只有 5 种类型，Tab 切换足够直观；业务人员操作路径短（选小程序 → 选类型 → 填参数 → 生成），不需要左右分栏的复杂度。且该项目的系统管理类页面（短链工具、证书合成等）都是单页布局，方案 A 更符合现有风格。
