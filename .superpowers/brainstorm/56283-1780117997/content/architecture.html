架构与文件结构

遵循项目现有分层模式：页面入口 → 服务层 → 组件 → Mock

文件结构

┌─ layers/sakai/app/pages/demo/system/miniapp/index.vue ← 页面入口
├─ layers/sakai/app/services/MiniAppService.ts ← 数据服务(API调用)
├─ layers/sakai/app/services/MiniAppMgrService.ts ← 页面状态(表单/结果/小程序列表)
├─ app/config/menu/system-menu.ts ← 菜单注册(+1条)
├─ mocks/handlers/miniapp.ts ← MSW Mock处理器
└─ mocks/data/miniapp.ts ← Mock数据

数据流

用户操作 服务层 API层
──────── ────── ────

1. 打开页面 ─────────────────→ MiniAppMgrService.loadMiniApps()
→ MiniAppService.getMiniApps() ─→ GET /api/miniapps
← 小程序列表 ← [{ id, name, appid }]

2. 填写表单 + 点击[生成有限码]
mgr.generate('wxacode') ──→ 校验参数
→ MiniAppService.generate({
appId, type:'wxacode',
path, width, ...
}) ────→ POST /api/miniapp/generate
← { imageUrl } / { link } ← 微信API返回
mgr.records.push(record) ← 加入会话记录

3. 点击[下载] ─────────────→ 触发浏览器下载 imageUrl
4. 点击[复制链接] ─────────→ navigator.clipboard.writeText(link)

菜单位置

加在「系统管理」菜单中，与「短链工具」「模板合成」同级：

...
├── 短链工具 (/demo/system/short-link)

├── 小程序工具 ← 新增 (/demo/system/miniapp)
└── 系统监控

MiniAppMgrService 核心状态

@Injectable()
class MiniAppMgrService {
// 小程序列表
miniApps: MiniApp[]
selectedAppId: string

// 表单参数
formPath: string // 页面路径 (必填)
formQuery: string // URL参数 (可选)
formEnvVersion: string // release/trial/develop
formWidth: number // 默认430
formIsHyaline: boolean
formScene: string // 无限码必填
formExpireType: string // Scheme/Link

// 会话生成记录
records: GenerateRecord[] // 仅内存，刷新清空

// 方法
loadMiniApps()
generate(type: GenerateType)
download(url: string)
copyLink(text: string)
validateFields(type: GenerateType): boolean
}
