错误处理 & 边界情况

覆盖校验规则、错误反馈、边界状态

前端参数校验（生成前）

校验项 规则 触发条件
未选择小程序 Toast: "请先选择小程序" selectedAppId 为空
path 为空 输入框红色边框 + 提示"页面路径不能为空" 所有类型（无限码是 page 字段）
scene 为空 输入框红色边框 + 提示"场景值不能为空" 仅 type=wxacodeunlimit
width 超出范围 自动修正到 280~1280，显示提示 仅二维码类型

API 错误处理

场景 用户反馈 处理
access_token 过期 Toast: "授权已过期，请刷新页面重试" 后端返回 401，前端提示刷新
配额已用完 Toast: "小程序码生成配额已用完(10万/个)，请联系管理员" 后端返回 429，显示明确原因
网络超时 Toast: "网络请求超时，请重试" 30s 超时，显示重试提示
微信接口报错 Toast: "生成失败：{微信返回的错误信息}" 后端透传微信错误信息

边界状态

空状态
  • 小程序列表为空 → 显示"暂无可选小程序，请联系管理员"
  • 会话记录为空 → 不显示结果区域，节省空间
加载状态
  • 加载小程序列表：下拉框显示 loading
  • 生成中：按钮 loading + 禁用，防止重复点击
  • 下载图片中：按钮文字变为"下载中..."
权限控制
  • 页面访问：菜单权限过滤（MenuService）
  • 如需要，可用 v-permission 指令控制按钮
  • 当前方案：有菜单权限即可使用全部功能
