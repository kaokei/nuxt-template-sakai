API 设计与 Mock 数据

两个接口：获取小程序列表 + 生成码/链接。MSW Mock 完整模拟回调流程。

接口 1：获取小程序列表

GET /api/miniapps

Response 200:
{
"code": 0,
"data": [
{ "id": "wx001", "name": "我的商城", "appid": "wxabc123..." },
{ "id": "wx002", "name": "内部OA", "appid": "wxdef456..." },
{ "id": "wx003", "name": "客户服务", "appid": "wxghi789..." }
]
}

接口 2：生成码/链接

POST /api/miniapp/generate

Request Body:
{
"appId": "wx001",
"type": "wxacode | wxacodeunlimit | qrcode | scheme | urllink",
"path": "pages/goods/detail",
"query": "id=123",
"envVersion": "release",
"width": 430,
"isHyaline": false,
"scene": "abc123", // 仅 type=wxacodeunlimit 时必填
"expireType": "permanent" // 仅 type=scheme/urllink
}

Response 200 (二维码类型):
{
"code": 0,
"data": {
"type": "wxacode",
"imageUrl": "data:image/png;base64,...", // base64图片
"contentType": "image/png"
}
}

Response 200 (链接类型):
{
"code": 0,
"data": {
"type": "scheme",
"link": "weixin://dl/business/?t=xxx",
"contentType": "text/plain"
}
}

Response 错误:
{
"code": 40001,
"message": "参数校验失败：path 不能为空"
}

Mock 行为设计

场景 Mock 返回 说明
正常生成二维码 一张占位图片(base64) 用简约的占位图模拟真实二维码返回
正常生成链接 weixin://dl/business/?t=mock_xxx 格式正确的模拟 Scheme 链接
path 为空 400 + 错误信息 验证前端校验逻辑
无限码 scene 为空 400 + 错误信息 测试类型特有参数校验
模拟 1 秒延迟 正常结果 显示 loading 状态，贴近真实网络延迟
